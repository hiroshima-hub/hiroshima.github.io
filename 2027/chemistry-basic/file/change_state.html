授業での読み方

  • 外圧を上げると、重りが増え、内圧との釣り合いに向かってピストンが下がります。
  • 箱が小さいことを圧力そのものとは扱いません。箱の縮小は、外圧による圧縮の結果です。
  • 内圧は、粒子の熱運動による項と粒子間相互作用による項から算出した瞬間値を平滑化して表示します。
  • 「ピストンを固定」を選ぶと、容積一定のまま温度・粒子数と内圧の関係を比較できます。
このモデルの圧力・温度は無次元量です。実在の水の Pa、℃、融点、沸点を直接再現するものではありません。また、K/N と |U|/N が等しくなることを相変化条件にはしていません。
教育用の単純化された2次元モデルです。実在分子の形、水素結合、3次元結晶、核生成、正確な相図は再現していません。
